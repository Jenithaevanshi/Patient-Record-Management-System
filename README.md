# Patient Record Management System

## Project Overview
A Python-based Patient Record Management System developed using Jupyter Notebook to manage and organize patient information.

## Objectives
- Organize patient information in a structured format.
- Practice Python programming concepts through a practical project.
- Demonstrate the use of Jupyter Notebook for Python development.

## Technologies Used
- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook

## Project File
- `Patient_Record_Management_System.ipynb` — Jupyter Notebook containing the project code and outputs.

## How to Run the Project
1. Download or clone this repository.
2. Open the notebook using Jupyter Notebook or Google Colab.
3. Run each code cell in sequence.
4. Follow the instructions displayed by the notebook.

## Learning Outcomes
- Practical application of Python programming.
- Hands-on experience with Jupyter Notebook.
- Development of a project to organize patient information.

## Privacy Notice
Use only sample or dummy patient information for demonstration. Do not upload real patient records or confidential medical information to a public repository.
